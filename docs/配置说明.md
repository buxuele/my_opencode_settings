# 配置说明

## config/AGENTS.md

全局规则，注入每次会话的系统提示。这里放必须每轮生效的硬规则：中文、零 emoji、工具调用方式、文档规范、代码规范、进程与内存纪律。规则要短，太长会挤占上下文。

## config/opencode.jsonc

主配置。当前关键项：

1. model 指定默认模型，与 opencode-mem.jsonc 里的供应商保持一致。
2. shell 指向 bin/zsh-wrapper，让 opencode 的终端工具走无头浏览器拦截。
3. permission 里 external_directory 白名单只放开代码目录与配置目录。
4. plugins 加载三个本地插件与 opencode-mem。
5. experimental.policies 封禁 openrouter 与 github-copilot，避免误用。
6. mcp 里只有 chrome-devtools 与 mac-mcp 两个，其余全部移除以省内存。

改动前先看注释，注释里记着当年为什么删掉某个服务。

## config/opencode-mem.jsonc

记忆插件配置。autoCapture 与 autoUpdate 关掉，避免后台常驻与自动改配置。存储路径用 ~ 开头，跨机器通用。

## config/cli.json

终端界面手感。滚动速度 1.5 不加速，差异按词换行，会话侧栏自动，思考过程隐藏，标签横向排列。换机器时这份文件最容易被忽略，但它决定操作手感。

## preferences/用户偏好.md

跨项目成立的稳定偏好，每条带观察日期与状态。整理节奏是 14 天，到期检查由 bin/preference-due.sh 提示。新证据推翻旧条目时把旧条目改成 superseded，不追加矛盾条目。

## commands/

斜杠指令，每个文件顶部有 description 与 agent 字段。日报指令依赖外部脚本，换机器时要么一起迁移，要么删掉该文件。

## skills/

技能目录，每个子目录一个 SKILL.md。openrouter-decisions 里带 scripts 与 references，体积不大，全部保留。

## plugins/

三个本地插件源码。node_modules 不进仓库，由安装脚本或 opencode 首次启动时安装。

1. remember-model 记住上次选的模型，新会话不回落默认。
2. session-title 自动生成会话标题。
3. auto-continue 模型中断时自动续跑，默认关闭。

## bin/

1. open 拦截器，把 open 一个 URL 转成本机 Chrome 无头截图，避免弹窗抢焦点。
2. zsh-wrapper，只把 bin 目录前置进 PATH，其余交给系统 zsh。
3. preference-due.sh，检查偏好文件多久没整理。
